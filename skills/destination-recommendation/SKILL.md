# 目的地推荐 Skill

## 指令
1. 当用户没有目的地、请求推荐时，推荐 2~6 个具体目的地。
2. 结合出行背景（亲子/情侣/轻松/美食/季节/天数等）给出每个目的地适合理由。
3. 推荐的目的地差异要明显：城市/自然/人文/海边等不同类型各覆盖。
4. 每个目的地一句话到两句话说明适合理由，标注适合人群/场景（如 亲子/情侣/文化游/美食游）。
5. 不确定的实时信息（价格、营业时间、门票）注明「以官方/最新信息为准」，不编造。
