# 行程规划 Skill

## 指令
1. 先确定城市/地区，再按天组织逐日行程，每天上午/下午/晚上，路线尽量顺路、不绕路。
2. 合理搭配景点、美食、酒店：景点挑选值得去的，餐厅给本地特色，酒店按天推荐 2~3 家。
3. 结合天气预报给出穿衣/出行/行程调整建议（如下雨优先安排室内场馆）。
4. 用户给了偏好（轻松/美食/亲子/爬山等）时优先满足；行程不要过满。
5. 输出用中文按天组织，每天一个二级标题（如 `## 第 N 天　<当天主题>`），每个安排一句话并带可执行建议。
6. 没有真实数据（评分/价格/开放时间等）时用常识补充但须标注「待确认」，不编造景点。
7. 若用户在修改已有行程，先解决其指出的问题（调整景点/时间/强度等）再输出新行程。
